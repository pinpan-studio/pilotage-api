# ADR-001 — Authentification par jetons Sanctum

## Contexte
Le portail web et l'application mobile doivent partager la même API.

## Décision
Utiliser Laravel Sanctum avec des jetons d'API, plutôt que des sessions.

## Conséquences
Un seul mécanisme pour le web et le mobile ; révocation des jetons possible par l'administration.

## Alternatives écartées
Passport (OAuth2 complet) : trop lourd pour le besoin.
